## [1.0.0] - 2024-01-01

### Added
- Core workflow engine with DAG execution
- Task system with retries, timeouts, and caching
- Context and state management
- Agent abstraction with tool support
- LLM integrations (OpenAI, Anthropic, Google AI, Mistral, Ollama)
- Database integrations (PostgreSQL, MySQL, MongoDB, Redis, Elasticsearch)
- Cloud integrations (AWS, Google Cloud, Azure)
- Messaging integrations (Slack, Discord, Telegram, Email, Webhook)
- Event system for workflow lifecycle
- Decorators for common patterns (retry, timeout, cache, rate_limit, validate)
- CLI interface
- Comprehensive documentation
- Example workflows
